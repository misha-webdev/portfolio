# MISHA BAILOV. — портфолио

Сайт-портфолио веб-разработчика: проекты, услуги, процесс работы и контакты.
Чистые HTML, CSS и JavaScript, без сборки, фреймворков и сторонних библиотек.

**Сайт:** https://misha-webdev.github.io/portfolio/
**Связаться:** [Telegram @mishabailov_web](https://t.me/mishabailov_web)

## Возможности

- Тёмный дизайн с градиентами и стеклянными элементами, шрифты Unbounded и Manrope.
- Адаптивная вёрстка: проверена на ширинах 360, 390, 768, 1024, 1440 и 1920 px.
- Анимации: появление блоков при прокрутке, живая сфера на главном экране с реакцией на мышь, бегущая строка. Всё движение отключается при системной настройке «Уменьшить движение».
- Доступность: ссылка «Перейти к содержимому», видимый фокус, мобильное меню с управлением с клавиатуры.
- SEO: мета-описание, Open Graph с картинкой для превью ссылки, canonical, разметка schema.org.
- Lighthouse пока не запускался.

## Запуск

Сборка не нужна: откройте `index.html` в браузере или через Live Server в VS Code.

## Публикация на GitHub Pages

1. Загрузите в репозиторий `portfolio` файлы `index.html`, `README.md` и папки `css/`, `js/`, `assets/`.
2. **Settings → Pages → Build and deployment:** источник **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–3 минуты сайт откроется по адресу `https://misha-webdev.github.io/portfolio/`.
4. Если адрес будет другим, обновите его в `index.html`: `canonical`, `og:url`, `og:image` и `url` в schema.org.
